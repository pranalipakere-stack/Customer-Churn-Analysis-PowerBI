# Power BI Data Analysis Project

## Overview
This project demonstrates data analysis and visualization using Microsoft Power BI. The CSV dataset is used as the data source to explore the data and present findings through interactive visualizations.

## Tools & Technologies
- Microsoft Power BI
- CSV Dataset

## Project Workflow
- Importing the CSV dataset into Power BI
- Exploring and preparing the data
- Creating visualizations and charts
- Presenting data through a Power BI report

## Project Files
- **Power BI Report (`Churn_Analysis[1].pbix`)** — Contains the report and visualizations.
- **Dataset (`Databel_-_Data[1].csv`)** — Source data used in the project.

## Learning Outcomes
- Gained practical exposure to Power BI.
- Learned how to work with CSV data sources.
- Developed an understanding of data visualization and report building.
